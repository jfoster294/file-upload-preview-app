# File Upload Preview App

A front-end file upload preview app where users can drag and drop files, preview uploads, check file details, remove previews, and validate file types.

## Live Demo

https://jfoster294.github.io/file-upload-preview-app/

## Features

- Drag and drop upload zone
- Click to choose files
- Image preview cards
- File name display
- File size display
- File type display
- File validation
- Reject unsupported file types
- Reject files over 5 MB
- Reject duplicate files
- Remove individual files
- Clear all files
- Upload summary stats
- Responsive design for mobile and desktop

## Accepted File Types

- JPG
- PNG
- GIF
- WEBP
- PDF
- TXT
- DOC
- DOCX

## Built With

- HTML
- CSS
- JavaScript
- File API
- Drag and Drop

## Project Goal

This project was built as part of my front-end developer portfolio to practice file handling, drag and drop interactions, validation, preview UI, DOM manipulation, and responsive design.
